# Tungsten Edge 钨极 v0.7.4

这一版有**两处行为变化会直接影响老用户**，请先看下面这两段——升级后如果觉得"某个功能没了"，多半就是它俩。其余是一个新设置、一处观感调整和两个修复。

## ⚠️ 最大化避让改成默认关闭

「窗口最大化时把底边抬到任务条上方」这个功能，以前是**一直开着、关不掉**的。这一版把它做成了菜单里的一个勾选项，**并且默认不勾选**。

也就是说：**升级后避让会消失**。想继续用的话，点菜单栏图标 → 勾上「最大化窗口避开任务条」，立刻恢复原来的行为。

为什么改成默认关：这是钨极里唯一一个会**真的去改写别的应用窗口尺寸**的功能，而且带着几个改不掉的小毛病（被抬起的窗口第一次点绿色缩放键可能先弹回铺满一次、外接非视网膜屏上写入会慢半拍）。没主动选择过的人不该被动地被改窗口，所以把选择权交回给你。

取消勾选是**立刻生效**的：已经被抬起来的窗口会马上长回铺满，不用等下一次最大化。

## ⚠️ 系统 Dock 那一组菜单重做了

菜单里原来的「隐藏系统 Dock / 显示系统 Dock」这条命令**已经删掉**。一键显隐交还给 macOS 自己的 **⌥⌘D**（Option+Command+D），那个快捷键一直都在、一直有效。

原因是那条命令名不副实：它只切换了系统 Dock 的自动隐藏开关，而"隐藏但仍可唤出"的 Dock 对贴着屏幕底边的钨极来说反而是持续干扰——你以为它藏起来了，鼠标一到底边它又冒出来抢位置。

现在这一组是：一条滑杆（从「常驻」到 3 秒，最右端是「不唤醒」＝真正藏起来不再冒出来）+ 一个确认按钮。**拖完滑杆要按一下确认才会生效**——因为每次修改系统 Dock 设置都必须重启 Dock，屏幕会闪一下，这一下消除不掉，只能让它发生在你主动确认之后，而不是拖到一半就突然闪。

## 图标不再按状态变淡

以前应用被最小化或已退出时，它在任务条上的图标会变淡/变灰。这一版**取消了这个淡化**——任何状态下图标都是全彩，状态只由图标下方的小圆点表示（有点＝运行中，没点＝已退出）。

代价是"最小化的单窗口应用看起来和活跃的一模一样"，这是有意接受的：淡化让整条任务条显得脏，而且浅色模式下几乎看不出差别，反而不如小圆点清楚。

## 新增：可以关掉鼠标悬停的动效

菜单里新增勾选项「鼠标悬停显示应用名」，默认勾上（＝保持原来的手感）。

取消勾选后，鼠标划过任务条时**完全静止**：图标不放大、不冒出应用名、固定文件夹格也不再放大。适合觉得原来那套跟着鼠标动来动去太闹的人。

有一个副作用值得一提：带标题的窗口卡片在悬停时会冒出应用名当副标题，副标题一宽整张卡就变宽，**它右边的所有卡片会跟着平移**。取消勾选可以消掉这个位移。

标题太长时弹出的全文浮层两种设置下都保留——那是看全被截断标题的唯一途径，而且它浮在任务条上方，不会推动任何卡片。

## 修复

- **消息区图标在非中等尺寸下小一号**。任务条设成小 / 大 / 特大档时，消息区的图标没跟着缩放，仍按中档尺寸渲染；小档下还会被面板裁掉一点。
- **最小化窗口时飞书主窗口被莫名带到最前**。最小化一个窗口后，焦点本该回到它下面那个窗口，但如果飞书在运行，它的主窗口经常会被顶上来。原因是飞书会在后台停放一批**看不见、没有标题、横贯整个屏幕宽度**的窗口，它们被误认成了"下面那个窗口"。

## 安装

下载 `Tungsten-Edge-0.7.4.dmg`，拖进「应用程序」即可。

或用 Homebrew：

```
brew install --cask moonbai-studio/tungsten-edge/tungsten-edge
```

**首次打开**：这个包没有 Apple 开发者签名，macOS 会拦一下。右键点图标选「打开」，或到「系统设置 → 隐私与安全性」里点「仍要打开」。

**需要辅助功能权限**：任务条要读取和操作窗口，第一次启动会引导你去授权。
