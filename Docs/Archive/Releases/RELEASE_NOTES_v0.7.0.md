# Tungsten Edge v0.7.0

相比 v0.6.6，本版本改进了系统 Dock 的控制方式，调整了快捷键，并修复了一个会在任务条上留下空图标的问题。

## 新增功能

- 「隐藏系统 Dock」现在是真正的彻底隐藏：原生 Dock 收起后，鼠标碰到屏幕底边也不会再弹出来；选择「显示系统 Dock」时，会恢复你隐藏前原有的唤醒延迟。
- 状态栏菜单新增「打开系统 Dock 设置…」，直接跳转到系统设置里的 Dock 配置页（Ventura 及以上为「桌面与程序坞」，macOS 12 为「程序坞与菜单栏」）。
- 钨极自身的显示 / 隐藏快捷键从 `⌥⌘E` 改为 `⌥⇧⌘D`，把 `⌥⌘E` 让回给 Safari 的「清空缓存」和访达的「推出所有磁盘」。
- 卡片菜单里的「标记为消息应用」改用固定标题加原生勾选标记，不再在「标记」和「取消标记」两种文字之间来回切换。

## Bug 修复

- 修复少数应用（如 Tailscale）被误判为有可用窗口、加入任务条后，留下一个永远不会消失的空图标的问题。

## 其他

- 钨极已以 GPL-3.0-or-later 开源，安装包与 DMG 内均附带完整许可证文本。
- 中文 README 加入了微信交流群入口，欢迎来反馈问题。

---

本版本仍未做苹果签名与公证，首次打开需要手动放行一次：右键（Control + 点击）图标选「打开」，或在「系统设置 → 隐私与安全性」里点「仍要打开」。首次运行还需在「系统设置 → 隐私与安全性 → 辅助功能」中授权。
