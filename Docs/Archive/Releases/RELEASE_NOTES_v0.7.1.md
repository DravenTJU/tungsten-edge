# Tungsten Edge v0.7.1

相比 v0.7.0，本版本把系统 Dock 的控制方式改回和 macOS 一致，并新增了两个大家要求的开关：可以关掉中转站，也可以调整任务条大小。

## ⚠️ 行为变化（升级前请先看这条）

- **「隐藏系统 Dock」的作用变了。** v0.7.0 里它是「彻底隐藏」——收起原生 Dock 的同时，把唤醒延迟一并改成不唤醒。现在它**严格等于系统自带的 `⌥⌘D`**：只切换自动隐藏，**不再改动你自己设置的唤醒延迟**，菜单里也直接标出了 `⌥⌘D` 这个快捷键。
- **「碰到屏幕底边也不弹出」这个能力没有消失**，换到了新加的滑杆右端：把系统 Dock 那条滑杆拖到 `不唤醒` 即可，效果和原来的彻底隐藏一样。
- 如果你升级前正处在彻底隐藏状态，升级后打开菜单会看到滑杆停在 `不唤醒`——这是真实状态，想改随时拖回来。

## 新增功能

- **系统 Dock 唤醒滑杆**：状态栏菜单里的系统 Dock 一组现在和钨极自己那组完全对称——一条显示 / 隐藏命令加一条 `常驻 ←→ 不唤醒` 滑杆，可以直接设置原生 Dock 的唤醒延迟（`常驻`、`0.1s`–`3.0s`、`不唤醒`）。滑杆松手才生效，因为每次写入都要重启一次系统 Dock。
- **可以关掉中转站**：菜单新增「显示中转站」勾选项。取消勾选只是把图标藏起来，已经暂存的文件引用照旧保留，勾回来还在。（感谢 issue #3 的反馈）
- **任务条大小可调**：菜单新增「任务条大小 ▸」，小 / 中 / 大 / 特大四档，任务条和右侧胶囊一起缩放——图标、文字、间距、圆角、条高都跟着走。默认是「中」，与旧版本完全一致，不改这个设置的话观感不变。

## Bug 修复

- 修复窗口标题在任务条上被截断、却不弹出完整标题气泡的问题（标题宽度和判定阈值原本是两处各自写死的数值）。

## 已知边界

- 如果你既关掉了中转站、又一个固定文件夹都没有固定，任务条上的文件夹区会整体消失，此时没有地方把文件拖进来，右键菜单里的「添加文件夹…」也会一并消失。在菜单里重新勾上「显示中转站」即可恢复。
- 任务条缩放本轮只作用于任务条本体和右侧胶囊；抽屉内部、文件夹弹窗和中转弹窗维持原尺寸。

---

本版本仍未做苹果签名与公证，首次打开需要手动放行一次：右键（Control + 点击）图标选「打开」，或在「系统设置 → 隐私与安全性」里点「仍要打开」。首次运行还需在「系统设置 → 隐私与安全性 → 辅助功能」中授权。
