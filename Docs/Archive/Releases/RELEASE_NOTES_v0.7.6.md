# Tungsten Edge 钨极 v0.7.6

这一版是三个修复，都来自同一位用户的详细反馈。**其中一处升级后会直接看出来**：重启电脑之后，你排好的应用图标顺序现在会保持住了。另外两处是小圆点状态和多余图标。没有新功能、没有拿掉任何你选过的东西。

## ⚠️ 重启电脑后，保留的应用图标顺序会保持了

以前重启一次 Mac，任务条上那些勾了「在程序坞中保留」的应用图标，顺序就会被打乱——它们会退回到你当初勾选保留的先后顺序，而不是你后来拖出来的顺序。

这一版修好了：**你拖出来的应用图标顺序会跨重启保持**。

有两点要说清楚：

- **窗口卡片的顺序仍然不跨重启保留。** 窗口的身份只在这一次开机周期内有效，重启之后就是另一扇窗了，谁也没法把它认回原位。所以重启后你会看到：应用图标各就各位，窗口卡片重新排过。这是有意的，不是没修干净。
- 开机登录时任务条通常比大部分应用先起来。晚一步出现的应用，它的窗口也会按记住的名次落位，不会掉到最右边。

## 修复：应用退出后，小圆点不再残留

有用户发现，某些应用明明已经退出了，系统程序坞里的运行指示点已经消失，钨极这边却还亮着。

根因是运行状态**只依赖系统的启动/退出通知**——这个通知一旦丢失（睡眠、锁屏期间最容易发生），那条记录就会永久留着，没有任何机制去纠正它。

这一版加了一层兜底核对：切换应用、系统唤醒、解锁屏幕时都会重新对一遍账。判断进程是否存活仍然只认操作系统层面的确切信号，不会因为查询接口一时查不到就误撤圆点。

顺带统一了圆点的含义：它表达的是「这个应用当前以正常应用身份在运行」，和系统程序坞一致，而不是「某个同名的后台进程还活着」。

## 修复：多进程应用不再多出一张图标

WPS Office 这类应用会同时跑好几个进程。以前钨极是**逐个进程**决定要不要显示应用图标的，于是那个没有窗口的进程会自作主张挂一张写着应用名的图标，贴在真实窗口卡旁边——两个窗口显示成三张卡。

现在这个判断改成**整个应用一起做**：只要这个应用还有任何一个窗口开着，就不再显示应用图标；所有窗口都关了才显示一张。

这不是给 WPS 打的补丁，凡是「同时跑多个进程、共用一个应用身份」的应用都适用。同一次还修掉了一个更少见的情况：这类应用全部进程都没窗口时，以前会叠出好几张一模一样的图标。

## 安装

下载 `Tungsten-Edge-0.7.6.dmg`，拖进「应用程序」即可。

或用 Homebrew：

```
brew install --cask moonbai-studio/tungsten-edge/tungsten-edge
```

**首次打开**：这个包没有 Apple 开发者签名，macOS 会拦一下。右键点图标选「打开」，或到「系统设置 → 隐私与安全性」里点「仍要打开」。

**需要辅助功能权限**：任务条要读取和操作窗口，第一次启动会引导你去授权。
