# Tungsten Edge v0.6.6

相比 v0.6.5，本版本增加了一些应用操作，并修复了多项影响任务条长期稳定性的问题。

## 新增功能

- 未运行的保留应用和消息应用，右键菜单新增「打开」。
- 已退出的消息应用现在会灰显，与其他未运行应用的状态保持一致。
- 所有卡片菜单统一把「退出 App」放在最后，菜单顺序更加一致。

## Bug 修复

- 修复保留应用或消息应用退出、重新启动时，卡片先出现在任务条末尾、再滑回原位置的问题。
- 修复部分无法可靠识别主窗口的应用被自动加入消息区后，同时出现在消息区和窗口区的问题。
- 修复部分消息区入口点击后无法正确重新打开应用主窗口的问题。
- 修复系统短暂丢失应用进程信息时，仍在运行的应用被误判为退出，导致窗口卡片被删除并重新生成、短时间出现重复卡片的问题。
