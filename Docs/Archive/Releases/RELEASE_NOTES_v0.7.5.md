# Tungsten Edge 钨极 v0.7.5

这一版把设置从「只活在菜单栏图标里」搬出来，做成了一页式设置窗口，并重排了状态栏菜单。**有一处行为反转老用户会直接感觉到**：菜单里那条可点的「显示/隐藏 Tungsten Edge 钨极」命令没了，四个外观开关（显示中转站 / 鼠标悬停显示应用名 / 最大化窗口避开任务条 / 任务条大小）也搬进了设置窗口。先看下面这两段——升级后如果觉得「某个功能没了」，多半就是它俩。其余是一个新入口、一处手感修复和几个内部改进。

## ⚠️ 菜单里「显示/隐藏 Tungsten Edge 钨极」命令删除了

以前菜单里有一条「显示 / 隐藏 Tungsten Edge 钨极」命令，点一下在「常驻」和「上次那档自动隐藏」之间切。**这一版把它删掉了**，换成一行灰色标题「Tungsten Edge 钨极（⌥⇧⌘D 显隐）」——和「系统 Dock（⌥⌘D 显隐）」那行完全对称，只标明快捷键、本身不可点。

切换常驻 / 自动隐藏现在有两条路：

- 拖菜单里钨极那一组的「自动隐藏」滑块（滑块仍在菜单里）
- 按全局热键 **⌥⇧⌘D**（这个热键独立注册，**不受这次改动影响**，照常工作）

为什么删：菜单里「打开系统 Dock 设置…」和「隐藏 Tungsten Edge 钨极」隔着分隔线仍像一对——根因是整个菜单只有系统 Dock 那组有标题行当「帽子」，下面的东西看着都归它管。给钨极那组也补了帽子之后，这条命令就没有位置了。

## ⚠️ 四个外观开关搬进了设置窗口

「显示中转站」「鼠标悬停显示应用名」「最大化窗口避开任务条」「任务条大小」这四项，**以前在菜单里，现在只在设置窗口里**。升级后菜单里找不到它们不是功能丢了，是搬了家。

打开设置窗口：点菜单栏钨极图标 →「设置…」，或按 **⌘,**（逗号）。每项都配了一行灰色说明。

两条唤醒滑块（钨极自动隐藏、系统 Dock 自动隐藏）**仍留在菜单里**——它们是滑块，要边拖边看，不适合放设置窗口。设置窗口里只留了指路文案告诉你去哪调。

## 新增：一页式设置窗口

这是这次的本意。起因是有用户发现按 ⌘, 会开出一个**完全空白**的窗口——那是早期为凑 SwiftUI Scene 留下的占位，恰好只有还没授权、已经卡住的用户才会撞见。顺带发现菜单栏里应用名叫 `macos-dock-cc-v2`（不是「Tungsten Edge 钨极」）。

这一版做了正式的设置窗口，分四节：

- **通用**：登录时启动
- **任务条**：显示中转站 / 鼠标悬停显示应用名 / 最大化窗口避开任务条 / 任务条大小（四项各带说明），并指路「自动隐藏和唤醒时间在菜单栏图标里调」
- **系统 Dock**：指路 +「打开系统 Dock 设置…」按钮
- **关于**：版本号 + 检查更新

菜单栏应用名也改回了「Tungsten Edge 钨极」。

## 新增：右键任务条弹菜单

右键点任务条两端的内缩边距、区域分割线、或抽屉胶囊，会弹出和状态栏图标**同一个**菜单，底边贴着任务条上沿、左边对齐鼠标，不再盖住任务条。

刻意不响应的地方：chip（应用图标）之间那 8pt 窄缝——瞄图标差几 pt 落进窄缝时弹出钨极菜单、顶掉那个 app 自己的菜单，比什么都不弹更糟。要右键某个应用，请直接右键它的图标。

## 修复：菜单划过选项的粘滞感

以前在钨极弹出的菜单里，鼠标划过选项会有「粘一下、跟手慢半拍」的感觉。三个菜单（状态栏图标 / 任务条右键 / 应用图标右键）都有，而应用图标那个菜单和状态栏菜单没有一行共同代码——共同点只有「由钨极弹出」。

根因是钨极为底边唤醒装的全局鼠标监视器：它在系统底层是事件拦截器，钨极自己弹菜单时主循环切进事件跟踪模式、拦截器不被服务，每个鼠标移动事件都要等超时才送达菜单。这一版在菜单跟踪期间摘掉监视器、结束时装回。划起来现在跟手了。

同一轮还顺带修了几个感觉不到但真实存在的毛病：

- 打开菜单时主线程被约 100ms 的同步系统读取卡住（登录项 / 系统 Dock 偏好 / 辅助功能权限），现全部移到后台队列，菜单开着时主线程零占用。
- 右键菜单锚点最多会偏 42pt（拖过系统 Dock 滑块没点确认时触发），现在先摆好菜单再量高度。
- 菜单在屏期间不再增删行、只改文字与勾选，避免高度跳、底边漂。

## 安装

下载 `Tungsten-Edge-0.7.5.dmg`，拖进「应用程序」即可。

或用 Homebrew：

```
brew install --cask moonbai-studio/tungsten-edge/tungsten-edge
```

**首次打开**：这个包没有 Apple 开发者签名，macOS 会拦一下。右键点图标选「打开」，或到「系统设置 → 隐私与安全性」里点「仍要打开」。

**需要辅助功能权限**：任务条要读取和操作窗口，第一次启动会引导你去授权。
