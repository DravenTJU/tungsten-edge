# Tungsten Edge 钨极 v0.7.3

这一版专修点击图标启动应用时的三个毛病，都是 v0.7.2 用户能直接碰到的。没有新功能，交互和设置一律不变。

## 图标弹跳不再中途卡死

点图标启动应用时，图标会上下弹跳表示"正在启动"。之前只要**鼠标从图标上移开，弹跳就会停在最高点不动**，有时还会变成斜着乱跳。

原因是弹跳动画和鼠标悬停动画在抢同一个位置属性，鼠标一移开，悬停那边的动画就把弹跳顶掉了——顶掉的时刻正好是抬到最高点。这一版把弹跳动画隔离出来，不再被别的动画打断。

顺带把"应用到底起来没有"的判断也修了：之前有些应用会在启动后一秒内被误判成"起好了"而提前停跳，现在改成等真实窗口出现才停。

## 剪映等应用点图标打不开

如果一个应用的安装包里藏着**和它同名同身份的后台小助手**（剪映专业版就是这样，它内部带了两个），那么点任务条上的图标时，系统会认为"这个应用已经在运行了"，于是只把那个没有窗口的后台助手唤到前台，主程序压根没被打开——表现就是**点了没反应，但用启动台能正常打开**。

这一版明确告诉系统"我要开的就是我指定的这个程序，不许拿别的顶替"，同时在多个同身份的包里主动挑出真正的主程序。

## 系统设置弹跳 20 秒、点不了最小化

点「系统设置」图标，应用能打开，但图标会一直弹跳约 20 秒才停，这期间点图标毫无反应，之后也没法用它最小化窗口。

三个症状是同一个原因：系统设置的主窗口**没有标题**，而任务条此前要求"窗口必须有标题"才认，于是它的窗口从来没被收进任务条——图标一直是个"应用入口"而不是"窗口卡片"，既等不到"窗口出现了"这个停跳信号，也没有可以最小化的目标。

这一版允许"没有标题但确实是标准窗口、尺寸也正常"的窗口进入任务条。系统设置现在和普通应用一样：打开就立刻停跳，图标上显示「系统设置」，点一下即可最小化。

（顺带纠正一条记录：此前推测这是 Catalyst 应用的通病，实测不是——它就是普通应用，只是窗口没填标题。）

## 安装

下载 `Tungsten-Edge-0.7.3.dmg`，拖进「应用程序」即可。

或用 Homebrew：

```
brew install --cask moonbai-studio/tungsten-edge/tungsten-edge
```

**首次打开**：这个包没有 Apple 开发者签名，macOS 会拦一下。右键点图标选「打开」，或到「系统设置 → 隐私与安全性」里点「仍要打开」。

**需要辅助功能权限**：任务条要读取和操作窗口，第一次启动会引导你去授权。
